# Strict Git Push Policy

## CRITICAL RULE: NEVER AUTO GIT PUSH
Under no circumstances should the AI agent execute `git push` autonomously or on its own initiative.

### Explicit Directives:
1. **Never Run `git push` Automatically**: Even after fixing bugs, building pages, editing styles, or committing code, NEVER push to remote repository on your own ("nije nije git push korbe na").
2. **Push Only on Direct User Request**: Execute `git push` ONLY when the user explicitly and directly instructs you to push (e.g., "git push koro", "git hard push koro", "push to github").
3. **Commit vs Push**: You may make local commits if necessary, but NEVER run `git push` without unambiguous user permission.
